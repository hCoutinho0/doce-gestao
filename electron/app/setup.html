Confeitto

Os dados ficam no seu projeto do Supabase, então você e quem mais usar o Confeitto veem as mesmas informações em qualquer computador.

A chave fica guardada só neste computador.

Conectar ao banco de dados

Copie estes dois dados do seu projeto no Supabase.

  1. Abra o projeto em supabase.com.
  2. URL: menu Project Settings → Data API, campo Project URL.
  3. Chave secreta: Project Settings → API Keys, a secret key (ou a service_role na aba das chaves antigas).
